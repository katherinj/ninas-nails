# Nina's Nails 💅

A boutique nail salon website for Nina's Nails, built with React, TypeScript, and Vite. Designed with a modern, luxurious aesthetic using a pastel accent palette on a clean white base.

---

## Tech Stack

- **React 18** — component-based UI
- **TypeScript** — full type safety
- **Vite** — fast dev server and build tool
- **Atomic Design** — scalable component architecture
- **CSS-in-JS (inline styles)** — theme-driven styling via React context

---

## Design System

The site uses a pastel accent palette on a white base. Pastels are used for:

- Accent dots and pills on service cards
- Nail illustration colors in the hero
- Icon tints in the contact section
- Gallery swatch backgrounds
- Stat numbers and logo highlight

| Token        | Default   | Description                           |
| ------------ | --------- | ------------------------------------- |
| `accentLav`  | `#9B8FD4` | Primary accent — logo, headings, CTAs |
| `accentPink` | `#C96FA0` | Secondary accent — contact, tags      |
| `accentBlue` | `#6094D4` | Tertiary accent — icons, tags         |
| `pastelLav`  | `#CEC6F4` | Light lavender fill                   |
| `pastelPink` | `#F2C4D8` | Light pink fill                       |
| `pastelBlue` | `#B8D4F8` | Light blue fill                       |
| `pastelMint` | `#B8E8DA` | Light mint fill                       |

## Sections

| Section      | Description                                    |
| ------------ | ---------------------------------------------- |
| **Navbar**   | Sticky nav with logo, links, and CTA           |
| **Hero**     | Full-bleed split layout with nail illustration |
| **Ticker**   | Service category strip                         |
| **Services** | Card list with pastel tags and pricing         |
| **About**    | Studio story, Nina's bio card, stats           |
| **Gallery**  | Asymmetric photo grid (5 swatches)             |
| **Contact**  | Address, phone, email, hours + map placeholder |
| **Footer**   | Logo, copyright, social links                  |
